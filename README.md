# Zenata Voyages

Site de l'agence Zenata Voyages (Oran, depuis 1984). Il s'ouvre quand on scanne le QR code de la carte de visite.

**Adresse en ligne :** https://oranovaagency.github.io/Zenata-Voyages/

> Le dépôt doit s'appeler exactement `Zenata-Voyages` : cette adresse est imprimée dans le QR code de la carte de visite.

Pour changer un numéro, l'email ou l'adresse : modifier `AGENCY` en haut du script dans `index.html`.

Hébergement : GitHub Pages → Settings → Pages → *Deploy from a branch* → `main` / root.

Réalisé par Oranova.
